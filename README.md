# SkinSight AI - React Landing Page

A modern, responsive React landing page for SkinSight AI, featuring AI-powered skin health screening technology. This project showcases a clean, professional design with smooth animations and interactive elements.

## 🚀 Features

- **Modern Design**: Clean, professional layout with gradient accents and smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Interactive Components**: Engaging animations and hover effects
- **Accessibility**: Built with accessibility best practices
- **Performance**: Optimized for fast loading and smooth interactions

## 🛠️ Technologies Used

- **React 18**: Modern React with hooks and functional components
- **CSS3**: Custom CSS with modern features like Grid, Flexbox, and animations
- **Inter Font**: Clean, modern typography
- **Responsive Design**: Mobile-first approach with breakpoints

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd skinsight-ai
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🎨 Design Approach

This landing page features a different design approach compared to the original:

### Key Design Differences:
- **Color Scheme**: Modern gradient-based color palette with blues, purples, and accent colors
- **Typography**: Inter font family for clean, professional appearance
- **Layout**: Card-based design with floating elements and interactive animations
- **Visual Elements**: 3D-style icons, gradient backgrounds, and smooth transitions
- **User Experience**: Interactive step-by-step process with animated navigation

### Components Structure:
- **Header**: Fixed navigation with mobile menu
- **Hero**: Animated hero section with phone mockup and floating elements
- **Features**: Grid-based feature cards with hover effects
- **How To Use**: Interactive step-by-step process with navigation
- **Footer**: Comprehensive footer with social links and navigation

## 📱 Responsive Design

The application is fully responsive with breakpoints for:
- Mobile devices (320px - 768px)
- Tablets (768px - 1024px)
- Desktop (1024px+)
